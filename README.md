# Becky’s Love

A responsive, single-page fan-inspired microsite styled around the supplied Runaway campaign imagery: warm vintage interiors, a twilight garden, blush florals, and editorial serif typography.

## Preview locally

Open `index.html` in a browser. The page uses plain HTML and CSS; its typefaces load from Google Fonts when connected to the internet.

## Publish with GitHub Pages

In the repository settings, open **Pages** and select **Deploy from a branch**, then choose `main` and `/ (root)`. The site will be served from `index.html`.

## Assets

The supplied reference images are in `assets/` and are used in the hero, garden feature, and exhibition sections.
